# UPGRADE — Android prototype

Это первая версия приложения: персонаж, уровень, XP и кнопка выполнения задания.

## Облачная сборка
1. Создай бесплатный аккаунт GitHub.
2. Создай новый репозиторий.
3. Загрузи содержимое этого проекта.
4. Открой вкладку Actions → workflow Build APK.
5. После завершения открой Artifacts → upgrade-debug-apk и скачай APK.

Дальше проект можно расширять: реальные задания, характеристики, персонаж, адаптивный AI и поиск работы.
